# Mobile Pause & Menu Buttons

为 ADOFAI Android PC 程序集移植版恢复常用的触屏按钮。

## 功能

- 游玩时显示右上角暂停按钮。
- 关卡选择界面显示打开游戏菜单的按钮。
- 显示暂停菜单和设置页面的返回按钮。

按钮使用游戏自带的暂停、菜单和返回操作。

## 适用范围

- ADOFAI Android 移植版 3.3.1，使用 PC 版游戏程序集。
- 需要 StArray Mod Manager Android 版。

其他游戏版本或官方移动版不在支持范围内。

当前正式版本为 1.6.0，已验证可用。

## 安装

1. 从 [Releases](https://github.com/iidamie/MobilePauseButton_Mobile/releases) 下载最新的 `MobilePauseButton-x.y.z.zip`。
2. 将 ZIP 解压到 Mod Manager 的 `mods` 文件夹。解压后应为：

   ```text
   ADOFAI/ModManager/mods/MobilePauseButton/MobilePauseButton.dll
   ```

3. 启动游戏，在 Mod Manager 中确认 **Mobile Pause & Menu Buttons** 已启用；如果刚启用过，请重启游戏。

## 卸载

在 Mod Manager 中停用该 Mod，或删除 `mods/MobilePauseButton` 文件夹，然后重启游戏。

## 按钮没有出现

请先确认游戏版本、安装目录结构和 Mod 启用状态。仍无法显示时，请提供 Mod Manager 日志中 `MobilePauseButton` 附近的内容。
